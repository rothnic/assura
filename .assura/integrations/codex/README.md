# Assura codex Integration

Generated by Assura agent integration lifecycle

This bundle is reviewable local glue and does not embed validation logic.
Installation writes only the bundle. Explicit activation patches only
Assura-owned project host configuration; host trust remains under user control.

## Wrapper

```bash
.assura/integrations/codex/assura-agent.sh
```

Set `ASSURA_AGENT_MODE` to one of `nudge`, `check`, `daemon-status`, or
`daemon-doctor`. For nudges, set `ASSURA_AGENT_EVENT` to `session-start`,
`before-tool`, `after-tool`, `file-read`, `idle`, or `recovery`.

Set `ASSURA_BIN=/absolute/path/to/assura` when the host hook should use a
specific Assura binary instead of the first `assura` on `PATH`.

## Host Configuration

From the project root, activate the generated integration with
`assura agent integration activate codex .`, then approve it in the host.
In Codex, use `/hooks` to approve the installed commands. The adapter checks
on `SessionStart`, `UserPromptSubmit`, `PreToolUse`, and `PostToolUse`. It uses
paths supplied by the tool and returns context only when Assura selects a nudge.

## Logging

Wrapper invocations enable Assura nudge logging by default. Each `nudge` call
appends a compact JSONL record to:

```bash
.assura/agent-sessions/nudges.jsonl
```

Set `ASSURA_AGENT_SESSION_ID` in the host integration to group records by agent
session. Set `ASSURA_AGENT_LOG=0` to disable logging or `ASSURA_AGENT_LOG_DIR`
to move the log directory.

## Shared Commands

Run these commands from the project root.

```bash
assura agent nudge --agent codex --event session-start --delivery automatic --format json .
assura agent nudge --agent codex --event before-tool --changed <path> --delivery automatic --format json .
assura agent nudge --agent codex --event after-tool --changed <path> --delivery automatic --format json .
assura agent nudge --agent codex --event file-read --changed <path> --delivery automatic --format json .
assura agent nudge --agent codex --event idle --delivery automatic --format json .
assura agent nudge --agent codex --event recovery --delivery automatic --format json .
assura check --format agent --agent codex --warn .
assura daemon status --format json .
assura daemon doctor --format json .
```
