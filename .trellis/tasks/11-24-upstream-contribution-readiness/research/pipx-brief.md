# pipx contribution brief

Target `pypa/pipx:main`, observed at `9bd278888b88af870e7c6d5da2e87fa49d1a5b59` on 2026-11-24. Pilot surface is `pipx run` and Codex.

- **Requirements.** Branch from `main` and reference an open issue. Search for existing reports first. A bug report needs expected and observed behavior, OS/shell/Python/pipx version and verbose output. The PR template expects descriptive text, regression coverage, docs where applicable, a `+topic.bugfix.rst` fragment for a behavior fix, `prek run --all-files`, and `tox run -e 3.11,3.15`. Keep the PR in draft until CI passes. [Guide](https://github.com/pypa/pipx/blob/9bd278888b88af870e7c6d5da2e87fa49d1a5b59/docs/contributing.rst), [bug template](https://github.com/pypa/pipx/blob/9bd278888b88af870e7c6d5da2e87fa49d1a5b59/.github/ISSUE_TEMPLATE/bug.md), [PR template](https://github.com/pypa/pipx/blob/9bd278888b88af870e7c6d5da2e87fa49d1a5b59/.github/PULL_REQUEST_TEMPLATE.md)
- **Observed review size.** Five recent contributor-authored CLI fixes and two maintainer-authored examples span 39–253 touched lines across 3–8 files, median 134 lines and 5 files. This is a small comparison sample. For this fix, aim for a command change, a regression test and a news fragment, and explain any broader change. [Contributor examples #2494](https://github.com/pypa/pipx/pull/2494), [#2487](https://github.com/pypa/pipx/pull/2487), [#2489](https://github.com/pypa/pipx/pull/2489), [#2479](https://github.com/pypa/pipx/pull/2479), [#2483](https://github.com/pypa/pipx/pull/2483), [maintainer examples #2499](https://github.com/pypa/pipx/pull/2499), [#2473](https://github.com/pypa/pipx/pull/2473)

Follow neighboring typed pytest tests with the local project fixture and test both backends. Preserve `--spec`, VCS and flag forwarding behavior. CI checks the supported Python matrix and lint/type/package jobs.
