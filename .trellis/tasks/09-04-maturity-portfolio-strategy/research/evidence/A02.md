## Observable contract

- `assura init --recipe-file <path>` accepts one explicit local YAML fragment,
  including a path with spaces; writes project-owned policy and records the
  supplied source path plus SHA-256 in
  `.assura/onboarding/profile-selection.json`.
- `assura agent onboard --recipe-file <path>` preflights an existing policy
  before onboarding baseline materialization. Mapping keys add, equal values
  are no-ops, scalar/non-`exclude` sequence conflicts preserve existing values
  with path/existing/incoming diagnostics, and explicit `exclude` values union
  in stable de-duplicated order. Valid writes use a same-directory atomic
  replacement.
- The catalog is ordinary local YAML only. It contains Rust-library, TS/Bun
  utility, and Python/pytest examples; it does not fetch remote content or
  execute templates. The CLI/spec/support/release-surface inventories and
  `docs/agent-patterns.md` describe the public flags and boundaries.
