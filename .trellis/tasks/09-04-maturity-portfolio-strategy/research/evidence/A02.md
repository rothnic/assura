## Observable contract

- `assura init --recipe-file <path>` accepts one explicit local YAML fragment,
  including a path with spaces; writes project-owned policy and records the
  supplied source path plus SHA-256 in
  `.assura/onboarding/profile-selection.json`.
- `assura agent onboard --recipe-file <path>` establishes explicit local intent
  before inferred baseline materialization for a new project and preflights an
  existing policy before writes. Mapping keys add, equal values are no-ops,
  scalar/non-`exclude` sequence conflicts preserve existing values with
  path/existing/incoming diagnostics, and explicit `exclude` values union in
  stable de-duplicated order. Valid writes use a unique, same-directory atomic
  replacement without overwriting a pre-existing temporary-named user file.
- Built-in `--recipe` recommendations provide Rust-library, TS/Bun utility, and
  Python/pytest layouts. A selected `--recipe-file` overlays every starter
  path, including built-in and project-intelligence starters, before provenance
  is written. No recommendation fetches remote content or executes templates.
  The CLI/spec/support/release-surface inventories and `docs/agent-patterns.md`
  describe the public flags and boundaries.

## Negative controls and repairs

- The first focused test failed because `--recipe-file` was unknown; the public
  init and onboarding argument surfaces were then added.
- A provenance test failed because no profile-selection record existed; source
  and content hash recording was added.
- The local-conflict test first showed onboarding had merged its baseline
  before reporting the collision. Preflight now rejects that conflict without
  modifying the existing config bytes.
- Fixture-backed checks rejected an implicit TS `components/` requirement, an
  invalid Python `test_.py` key, and a conventional nested `__init__.py`.
  The pattern catalog was narrowed to optional components, supported `.py`
  syntax, and a scoped package exception.
- Explicit exclude composition initially failed as a generic sequence conflict;
  only the selected pattern's `exclude` path now unions stably. A shell-looking
  recipe file is rejected as policy input and its marker is never executed.
- Independent review found that new-project onboarding applied inferred policy
  before local intent, that a predictable temporary filename could overwrite a
  user file, and that language examples were test-only. Focused red tests led
  to local-first materialization, create-new temporary files, and bounded
  first-party `--recipe` values. A follow-up review found `--recipe-file` was
  ignored by built-in starters; all starter paths now share the overlay renderer
  and the regression verifies the composed policy.
