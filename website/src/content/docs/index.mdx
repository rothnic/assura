## Current Release Surface

<CardGrid stagger>
  <Card title="assura check" icon="document">
    The primary supported validation command for local development and CI.
  </Card>
  <Card title="assura init" icon="setting">
    Creates a starter `.assura/config.yml` without overwriting existing config by default.
  </Card>
  <Card title="assura migrate" icon="seti:yaml">
    Converts supported LS-Lint configuration into Assura structure config.
  </Card>
  <Card title="JSON Reports" icon="list-format">
    Machine-readable reports expose success, paths, counts, and violations.
  </Card>
</CardGrid>

## Quick Example

```bash
cargo install assura
assura init
assura check --format json .
```
