## How To Read This Page

Use the table above for the product comparison: one Assura CLI run versus one
warm LS-Lint CLI run on the same generated fixture tree and equivalent ruleset.

The current headline is intentionally narrow. It covers generated, stable,
native LS-Lint-parity fixtures. Pinned Next.js and mdBook fixtures are available
behind an explicit opt-in flag because they clone third-party repositories.

## Updating The Baseline

Baseline updates are explicit source changes:

```bash
cargo run --quiet -- performance-report \
  --output benches/history/current.json \
  --history benches/history/ls-lint-comparison-history.jsonl \
  --website-dir website/public/data/performance \
  --iterations 5
```

Review the generated diff in `benches/history/` and
`website/public/data/performance/` before merging.

Pinned external repository evidence is intentionally separate from the default
refresh:

```bash
cargo run --release --quiet -- performance-report \
  --include-external-fixtures \
  --output target/performance/external-fixtures.json \
  --history target/performance/external-fixtures.jsonl \
  --website-dir target/performance/website-data \
  --iterations 3
```
