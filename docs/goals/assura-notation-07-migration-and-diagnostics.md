# Migration And Diagnostics

Provide the explicit bridge to Option A and make effective policy inspectable.

## Deliverables

- `assura migrate --from auto|ls-lint|assura-v1`.
- Validated Option A output without permanent native parser aliases.
- Preservation of LS-Lint exact extension-combination selectors without
  weakening native Assura `*.ext` compound-stem defaults.
- Explain output for source rule, rebased selector, precedence, threshold,
  severity, repair guidance, and checked status.
- Compiled-config schema bump and clean stale-artifact diagnostics.

## Proof Gate

- Representative legacy Assura and LS-Lint inputs migrate equivalently.
- Check, review, explain, and agent feedback use consistent rule terminology.
- Generated migration output parses and validates before it can be written.

## Completion Evidence

Explicit LS-Lint and legacy `@rule` migrations validate normalized output;
explain tests report source rules, rebased selectors, and repair context.
