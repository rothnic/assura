# Security Policy

## Supported Versions

Assura is pre-1.0. Security fixes target the latest public release and the
current `master` branch unless a release note says otherwise.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| `< 0.1.0` | No |

## Reporting A Vulnerability

Use GitHub private vulnerability reporting when it is available for this
repository. If private reporting is unavailable, open a minimal public issue
that names the affected surface without exploit details, then coordinate
details privately with the maintainer.

Please include:

- affected Assura version or commit;
- platform and install method;
- affected command, config field, or release asset;
- impact summary;
- minimal reproduction steps that do not expose sensitive data.

Security fixes can bypass normal roadmap sequencing. Release-blocking security
issues are tracked under the support policy in
[docs/support-policy.md](docs/support-policy.md).
